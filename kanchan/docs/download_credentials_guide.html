📧 Gmail API Credentials Setup Guide

⚠️ Important: This process requires a Google account and takes about 10-15 minutes.

Quick Start

  1. Go to Google Cloud Console
  2. Create/select a project
  3. Enable Gmail API
  4. Create OAuth credentials
  5. Download credentials.json

Detailed Steps

1 Create or Select Project
  • Visit console.cloud.google.com
  • Click project dropdown (top bar)
  • Click "New Project" or select existing
  • Name it "Email Bot" (or any name)
2 Enable Gmail API
  • Go to: APIs & Services → Library
  • Search: "Gmail API"
  • Click "Gmail API"
  • Click "Enable" button
3 Configure OAuth Consent Screen
  • Go to: APIs & Services → OAuth consent screen
  • Select "External" → Click "Create"
  • Fill required fields:
    • App name: "Email Bot"
    • User support email: Your email
    • Developer email: Your email
  • Click "Save and Continue" (3 times)
  • On "Test users" page: Add your Gmail address
  • Click "Save and Continue"
4 Create OAuth Credentials
  • Go to: APIs & Services → Credentials
  • Click "+ CREATE CREDENTIALS"
  • Select "OAuth client ID"
  • Application type: "Desktop app"
  • Name: "Email Bot Client"
  • Click "Create"
  • Copy Client ID and Client Secret (you'll need them)
5 Download credentials.json
  • In Credentials page, find your OAuth client
  • Click the download icon (⬇️) next to it
  • OR click client name → "Download JSON"
  • Rename file to credentials.json
  • Move to your project root folder
✅ File Location:
Your credentials.json should be in the same folder as:
email_bot_ui.py, gmail_service.py, etc.

Manual Creation (Alternative)

If download doesn't work, create credentials.json manually:

{
  "installed": {
    "client_id": "YOUR_CLIENT_ID.apps.googleusercontent.com",
    "project_id": "your-project-id",
    "auth_uri": "https://accounts.google.com/o/oauth2/auth",
    "token_uri": "https://oauth2.googleapis.com/token",
    "auth_provider_x509_cert_url": "https://www.googleapis.com/oauth2/v1/certs",
    "client_secret": "YOUR_CLIENT_SECRET",
    "redirect_uris": ["http://localhost"]
  }
}

Replace YOUR_CLIENT_ID and YOUR_CLIENT_SECRET with values from Step 4.

Verification Checklist

  • Project created/selected in Google Cloud
  • Gmail API enabled
  • OAuth consent screen configured
  • OAuth 2.0 credentials created (Desktop app)
  • credentials.json file exists in project root
  • Your email added as test user

Test It

  1. Run: streamlit run email_bot_ui.py
  2. Go to "Emails" tab
  3. Click "Process Unread Emails"
  4. Browser will open for Google authentication
  5. Sign in and grant permissions
  6. Success! 🎉
Security: Never commit credentials.json or token.pickle to git!
